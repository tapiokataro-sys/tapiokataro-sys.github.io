プライバシーポリシー

最終更新日: 2026年10月20日

「YouTube Uploader」（以下「本ツール」）は、YouTube チャンネル「なしこの政治ニュース」の運営者が、自分のチャンネルに動画をアップロードするために使う個人用ツールです。

取得する情報

本ツールは Google の OAuth を通じて、運営者自身の YouTube アカウントに対して次の権限のみを使います。

  • YouTube への動画のアップロード（youtube.upload）
  • チャンネル情報の読み取り（youtube.readonly）：アップロード先のチャンネル名を確認するため

情報の使い方と保存

認証情報（アクセストークン）は運営者のパソコン内にのみ保存され、外部のサーバーに送信・共有することはありません。取得した情報を広告や分析、第三者への提供に使うことはありません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

権限の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールのアクセス権を取り消せます。
